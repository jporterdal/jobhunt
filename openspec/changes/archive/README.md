# Archived changes

Each folder is one finished change, dated by when it was archived: its proposal, design, tasks and the spec deltas
that were merged into `openspec/specs/`. Read in date order, they are the project's design record.

Before this repository was published, the record was edited in one pass:

- Example values in scenarios, designs and measurement write-ups (people, organisations, places, courses, addresses,
  posting IDs and quoted posting text) were replaced with the invented cast described in
  [`docs/fictional-data.md`](../../../docs/fictional-data.md). Numbers and verdicts in measurement write-ups were kept;
  the postings they refer to are named `posting A`, `posting B`, … within each write-up.
- Mentions of where postings came from were rewritten in source-neutral terms.
- The first change, which added importing captured pages, is not included.

Nothing else was changed: requirements, decisions and their reasons read as they were written.
